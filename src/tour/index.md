# A tour of the panel

This part walks through the panel the way a new user meets it, a host
at a time, with a picture of each step. Every picture was taken by
Arcana's own browser test, against a test host called `lab` with four
jails (`cache`, `db`, `gw`, `web`), so what you see is what the panel
really shows. The host's real name on the test machine is `labvm`.
