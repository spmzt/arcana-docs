# Architecture

Arcana manages a fleet of FreeBSD hosts for one user: an agent on each
host, and a console that coordinates them. This chapter is Arcana's own
`docs/ARCHITECTURE.md`, included from its tree as it stands at the
commit the book was built from; the words Archive, Agent and
Orchestrator are explained in [The seven Archives](archives.md).
