book was built from:

| Page | Is |
|---|---|
| [arcana-agent(8)](reference/arcana-agent.md) | the agent on every host |
| [arcana-console(8)](reference/arcana-console.md) | the console |
| [arcana-enrol(8)](reference/arcana-enrol.md) | joining a host to the console |
| [arcanactl(8)](reference/arcanactl.md) | the agent from a shell |
| [jailconf(8)](reference/jailconf.md) | one value of `jail.conf`, changed in place |
